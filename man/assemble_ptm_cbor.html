Description

Assemble a final MuData file from compact CBOR stage artifacts

Usage

assemble_ptm_cbor(statistics_h5mu, enrichment_cbor, output_h5mu)

Arguments

statistics_h5mu Complete statistics artifact.
enrichment_cbor Every enabled CBOR artifact, including kinase preparations.
output_h5mu Final artifact.

Value

The complete final object, invisibly.
